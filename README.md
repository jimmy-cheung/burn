# OVERCLOCK

OVERCLOCK is a high-pressure system performance game where the player operates
the core OS of a silicon computer.

## Play

- Move through the arena to process clean data packets.
- Raise the frequency slider for faster processing and higher multipliers.
- Hold `Space` or the cooling button to reduce core temperature.
- Press `G` or run the garbage collector when memory leak reaches the danger zone.
- Survive thermal locks and keep the system alive as long as possible.

The public site is deployed to [burn.imjimmy.me](https://burn.imjimmy.me).
